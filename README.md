# AlgoArena

### Algorithms, but make them visible.

AlgoArena is an interactive web-based visualizer designed to make Data Structures and Algorithms easier to understand through step-by-step visualizations.

Instead of only reading how an algorithm works, AlgoArena lets you **watch the algorithm happen**.

## Features

- Bubble Sort visualization
- Selection Sort visualization
- Insertion Sort visualization
- Linear Search visualization
- Binary Search visualization
- Stack operations
- Queue operations
- Linked List operations
- Step-by-step animations
- Comparison, swap, and step statistics
- Responsive design
- Light and dark theme

## How It Works

1. Select an algorithm or data structure.
2. Generate the required data.
3. Start the visualization or perform an operation.
4. Observe the steps through animation.
5. Understand how the algorithm or data structure behaves.

## Project Goal

The goal of AlgoArena is to provide a simple and visual way for students and beginners to understand DSA concepts without relying only on theoretical explanations.
